# Lead.AI Labs — Hugging Face Collection Architecture & Plan

This document outlines the strategic plan for creating and curating **4 specialized Hugging Face Collections** under the [Lead.AI Labs Organization](https://huggingface.co/lead-ai-labs). 

Collections group related models, datasets, and Space applications into cohesive, professional showcases for prospective enterprise clients, researchers, and AI engineering teams.

---

## 📂 Collection 1: Lead.AI Fraud Shield

* **Collection Title:** Lead.AI Fraud Shield
* **Slug / URL Path:** `lead-ai-fraud-shield`
* **Short Description:** Explainable fraud detection models, datasets, and demos for fraud risk scoring and XAI workflows.
* **Target Audience:** Fintech risk officers, e-commerce payment teams, security automation engineers.

### Included Assets:
1. 🤖 **Model:** [lead-ai-labs/fraud-detection-xai](https://huggingface.co/lead-ai-labs/fraud-detection-xai)
   * *Role:* Primary explainable tabular classification model.
2. 📊 **Dataset:** [lead-ai-labs/fraud-detection-Table-data](https://huggingface.co/datasets/lead-ai-labs/fraud-detection-Table-data)
   * *Role:* Benchmark 100+ row tabular synthetic training dataset.
3. 📋 **Dataset:** [lead-ai-labs/fraud-detection-sample-data](https://huggingface.co/datasets/lead-ai-labs/fraud-detection-sample-data)
   * *Role:* Lightweight 25-row sample dataset for rapid prototyping.
4. 🖥️ **Space Demo:** [lead-ai-labs/lead-ai-fraud-shield-demo](https://huggingface.co/spaces/lead-ai-labs/lead-ai-fraud-shield-demo)
   * *Role:* Interactive Gradio application for real-time risk scoring and XAI attribution.

## ⚙️ Manual Creation Steps on Hugging Face

1. Navigate to [Hugging Face Organizations - Lead.AI Labs](https://huggingface.co/lead-ai-labs).
2. Click on the **"Collections"** tab and select **"Create new collection"**.
3. Enter the Collection Title and Description as specified above.
4. Add items using the search bar by typing `lead-ai-labs/...`.
5. Pin the **Lead.AI Fraud Shield** collection to the top of the organization profile.
