# Lead.AI Fraud Detection Model (`arun-gharami/lead-ai-fraud-detection-model`)

The **Lead.AI Fraud Detection Model** is a binary tabular classifier engineered for transaction risk scoring, credit card velocity analysis, and Explainable AI (XAI) experimentation. Developed by **Lead.AI Labs** ([www.lead-ai.us](https://www.lead-ai.us)).

## 📌 Model Overview

* **Model Repository:** `arun-gharami/lead-ai-fraud-detection-model`
* **Organization:** [Lead.AI Labs](https://huggingface.co/lead-ai-labs) / [Arun Gharami](https://huggingface.co/arun-gharami)
* **Official Website:** [www.lead-ai.us](https://www.lead-ai.us)
* **Primary Task:** Binary Tabular Classification (`0: Legitimate`, `1: Fraudulent`)
* **Framework:** Scikit-Learn / XGBoost with SHAP Attributions

## 🎯 Intended Use

* Real-time risk probability calculation for e-commerce checkout APIs.
* Prototype risk scoring engine for fintech proof-of-concept testing.
* Audit-ready decision support system for manual risk analyst review queues.

## 🚫 Limitations & Responsible AI Disclaimer
