# Lead.AI Fraud Detection Dataset (`arun-gharami/lead-ai-fraud-detection-dataset`)

The **Lead.AI Fraud Detection Dataset** (v1) is a lightweight tabular synthetic dataset engineered for rapid fraud classification experiments, API sanity testing, and demo validation by **Lead.AI Labs** ([www.lead-ai.us](https://www.lead-ai.us)).
